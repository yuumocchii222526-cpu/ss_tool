Aetherlight 修正版（ズーム・なめらかペン改善）

変更点
- プレビュー画像のズーム機能を追加
- 拡大（＋）、縮小（－）、100%に戻すボタンを追加
- 拡大中の表示位置移動に対応
- なめらかペン使用時、2本指で拡大・縮小・移動しやすいよう改善
- 拡大しても 100% ボタンで元の表示へ戻れるよう修正
- マウスホイールでも拡大・縮小可能

使い方
1. 既存の index.html を、この index.html に置き換える
2. GitHub にアップロードして Commit changes する
3. 公開URLを開き直す
4. 古い表示が残る場合は URL の最後に ?v=5 を付けて再読み込みする

操作のポイント
- ペン中：1本指でなぞる
- 拡大中：2本指で移動・拡大縮小
- 画面上の 100% ボタンで元の表示に戻す
- PCではホイール操作でもズーム可能

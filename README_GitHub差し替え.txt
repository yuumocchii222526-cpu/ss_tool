GitHub Pages更新方法
1. このZIPを端末で展開してください。
2. ZIPの中にある index.html だけを、GitHubリポジトリの一番上（root）にアップロードします。
   ※ ZIP自体をアップロードしてもGitHub Pagesのサイトは更新されません。
3. 既存の index.html を置き換えて Commit changes を押してください。
4. 公開URLを再読込します。古い画面が出る場合はURLの末尾に ?v=6 を付けます。
   例: https://ユーザー名.github.io/リポジトリ名/?v=6

操作
・＋で拡大、－で縮小、100%で表示を元に戻す
・ペン中は1本指でなぞり、2本指で表示拡大や移動
・編集後に「画像を保存」でPNG保存

備考
確認はChromiumブラウザで実施しました。Safari等の端末すべてでの動作保証ではありません。

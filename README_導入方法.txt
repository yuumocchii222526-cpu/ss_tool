GitHub Pages 更新方法

2. index.html、privacy.html、terms.html を GitHub ss_tool リポジトリのルートへ上書きアップロードします。
3. Commit changesを押します。
4. 公開完了後 https://yuumocchii222526-cpu.github.io/ss_tool/?v=26 を開いて確認してください。

重要：AI連携時には外部サービスの画像送信、利用料金、プライバシーポリシーを改めて確認・更新してください。

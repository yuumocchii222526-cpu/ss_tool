同梱ファイル：
・index.html　Aries Studio（旧 Aetherlight）画像編集ツール

更新手順：
1. ZIPを解凍します。
2. GitHub Pages の公開フォルダ（通常はリポジトリ直下）に、上記HTML 3ファイルをアップロードして上書きします。
3. Commit changes します。
4. 公開URLの末尾に ?v=13 を付けて再読み込みし、フッターの各リンクを確認してください。

Aries Studio v16 — スマホ用横型編集レイアウト

変更点
・ズームの +/-、倍率、100%ボタンを写真の外側へ移動
・iPhone等では写真を上に表示したまま、下部の編集ツールを操作可能
・メニューと各調整項目を横スクロール式に変更
・スライダーやプリセットを選んでも画像確認のためにページ全体を往復する必要がない設計
・デスクトップ版の元の2カラム構成と加工機能は維持
・プライバシーポリシー / 利用規約を同梱

GitHub Pagesへの反映
1. ZIPを解凍する
2. index.html / privacy.html / terms.html をリポジトリのルートにアップロードする
3. Commit changes を押す
4. キャッシュが残る場合、公開URL末尾に ?v=16 をつけて開き直す

注意：アプリ内のズーム倍率の100%は、写真の画面内表示の基準倍率です。

AriesStudio v28 — 背景ぼかし（被写界深度）

変更点
・「背景ぼかし」タブを追加
・手動のピント位置（画像をタップ）＋ぼかし強度調整
・端末内で動くオプションのAI奥行き推定（Depth Anything V2 Small）を追加
・保存画像に背景ぼかしを反映
・既存の横型UI、指で消す、フィルター、Copyright、iPhone保存は維持

使い方
1. 画像を読み込んで「背景ぼかし」を開く
2. 「ピント位置をタップ」→写真の人物をタップ
3. ぼかし量を設定（手動モードは初回通信なしで動作）
4. AIで奥行きを解析：初回のみモデルをダウンロード。ネット環境と端末性能が必要
5. 推定に失敗したり不自然な場合は「手動ピント」に切り替え可能

注意
- FF14スクリーンショットの深度はAIによる推定値であり、完全な被写体分離ではありません。
- ダウンロードするAIのライブラリ・モデルは第三者配信サービスから取得します。
- 写真をサーバーにアップロードする処理はありません。
- iPhone実機のAIモデル動作は未検証です。AIが利用できない場合も手動モードは機能します。
- モデル：onnx-community/depth-anything-v2-small（Apache-2.0）/ Transformers.js

GitHub Pages: ZIPを解凍し、index.html・privacy.html・terms.html をリポジトリの公開フォルダに上書きしてください。

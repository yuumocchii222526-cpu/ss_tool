Aetherlight - FF14 SS加工Webアプリ
================================

これは非公式のファンメイドSS加工ツールです。
HTML / CSS / JavaScript を1つにまとめた、サーバーなしで動く試作版です。

【PCで試す】
index.html をChromeやSafariなどのWebブラウザで開いてください。
「SSを選ぶ」から画像を読み込み、フィルターやスライダーで調整します。
「画像を保存」でPNG画像を保存できます。

【スマホで使う・URLで共有する】
Webサイトとして公開すると、スマホからも開けます。
GitHub Pagesを利用する場合は：
1. GitHubでリポジトリを作成
2. index.htmlをリポジトリの一番上にアップロード
3. Settings → Pages → Deploy from a branchを選択
4. main / (root)を選択して保存
5. 発行されたURLにスマホのブラウザからアクセス
※GitHub Pagesの公開サイトは基本的に誰でもアクセスできます。

【主な機能】
・PNG/JPG/WebP等のアップロード（対応形式はブラウザによる）
・8種類のプリセット
・色調調整、ブルーム、ソフトフォーカス、ビネット、粒子
・トリミング位置のドラッグ調整、白枠・シネマフレーム、署名
・加工前比較、PNG保存

画像は外部サーバーに送信されません。ブラウザ内で処理されます。
画像によってはメモリ制限に合わせて保存時の解像度を縮小します。

FINAL FANTASY XIVおよびSQUARE ENIXとは提携していません。

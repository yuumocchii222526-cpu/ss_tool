AriesStudio v35 — 写真にロゴを追加

・編集メニューに「ロゴ追加」追加
・端末内のロゴ画像（PNG/JPG/WebP）を読み込み、写真へ合成
・ドラッグ移動、大きさ、透明度、5か所へのワンタップ配置、削除
・写真のプレビュー・PNG保存・iPhoneの共有保存へ反映
・読み込んだロゴは外部に送信しません
・背景の透明なPNGがおすすめです。参考のスクショをそのまま選ぶと背景も一緒に重なります。
・既存の高画質スライダーなどの加工機能は維持
